Drop artwork image files in this folder.

Any .jpg .jpeg .png .webp .gif .avif file here appears on the site
automatically. No code change needed. Files are shown in filename
order, so prefix with numbers if you want a specific sequence.

The FIRST file in the folder is also used as the painting hanging on
the art wall in the gallery, so put the one you want as the cover
first. For example:

  01-eat-my-feelings.jpg      <- hangs on the wall, and leads the grid
  02-time-lapse.jpg
  03-portrait-charcoal.jpg

Titles and years come from the filename if you write them as
  title--year.jpg
for example
  04-willie-pete-is-running-wild--2024.jpg
